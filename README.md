# 善心记录

本地运行的 PWA，用于按日分类记录微信群红包善款（替代纸笔记账）。数据仅存于本机 IndexedDB，不上传服务器。

## 功能

- 选择记账日期（默认记住上次查看的日期）
- 六个分类：供养师父、常住随用、建寺、供僧、其他、放生
- 总善款 = 前五类之和；放生单独统计，不计入总善款
- 数字键盘录入，支持两位小数；每条记录带确认时间
- 点击记录可修改金额，左滑删除
- 一键复制善款汇总 / 放生信息到剪贴板

## 开发

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（如 `http://localhost:5173`）。

## 构建

```bash
npm run build
npm run preview
```

产物在 `dist/` 目录。

## 在 Vivo X200 Pro 上安装（不上应用商店）

1. 在电脑上执行 `npm run build`，将 `dist` 文件夹传到手机，或在同一 Wi‑Fi 下用电脑运行：
   ```bash
   npx serve dist
   ```
   手机 Chrome 访问电脑的地址（如 `http://192.168.x.x:3000`）。

2. 首次用 **Chrome** 打开页面，确保能正常显示。

3. Chrome 菜单 → **添加到主屏幕** / **安装应用**，即可像 App 一样从桌面打开。

4. 安装后支持离线使用（PWA 缓存页面资源）；记账数据保存在手机浏览器 IndexedDB 中。

**注意：** 不要用 `file://` 直接打开 `index.html`，否则 PWA 与部分 API 可能不可用。需通过 `http://` 访问。

## 使用提示

- 周日晚整理时，若在周一 00:15 仍在录入，请在首页左上角把日期选为 **周日**，再录入与复制。
- 复制善款汇总：仅包含金额大于 0 的分类行；总善款为 0 时按钮不可用。
- 复制放生信息：格式为 `YYYY-MM-DD 放生：xx.xx`。
